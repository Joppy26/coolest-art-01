Neon Koi Ascending: a koi fish made of glowing circuitry swims up through a night sky past a full moon, over a lantern-lit village far below. The program draws the whole scene from scratch in pure Python and writes it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
